SLC WEEKLY MARKET BRIEF — PUBLISHING GUIDE

Each Monday:

1. Open: src/content/market-briefs/
2. Copy _TEMPLATE.md.
3. Rename the copy to the Monday date, for example:
   2026-09-21.md
4. Update the frontmatter at the top:
   - title
   - date
   - slug
   - number
   - excerpt
5. Paste the finished brief below the frontmatter.
6. Save the file.
7. Open GitHub Desktop.
8. Commit the new file and Push origin.
9. Cloudflare rebuilds the website automatically.

The newest dated brief becomes the latest brief on the site automatically.
